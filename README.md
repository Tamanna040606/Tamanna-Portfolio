## 🚀 About the Project

Welcome to my personal developer portfolio!

This is a modern, interactive and visually immersive 3D portfolio designed to showcase my technical skills, educational background, projects and interests.

Built using React and Vite, the portfolio combines creative UI design, animated visual elements and interactive 3D effects to deliver an engaging browsing experience.

I'm Tamanna Kumari, a BCA student specializing in Artificial Intelligence and Machine Learning, passionate about software development, emerging technologies and building creative solutions.

## 🌟 Features

- **3D Interactive Design** – Dynamic 3D effects and interactive card animations.
- **Animated Background** – Particle animations, gradient atmosphere and visual effects.
- **Interactive Cursor Glow** – Smooth cursor-following lighting effect.
- **Loading Animation** – Custom animated loading screen.
- **Scroll Reveal Effects** – Sections animate into view while scrolling.
- **Responsive Layout** – Designed for desktop and mobile screens.
- **Skills Showcase** – Highlights programming, development and AI/ML skills.
- **Project Showcase** – Displays selected projects and their live demonstrations.
- **Education Timeline** – Presents academic achievements and journey.
- **Contact Section** – Quick access to professional contact and social profiles.
- **Back to Top** – Smooth navigation with scroll progress indicator.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Tamanna040606/Tamanna-Portfolio.git
```

### 2. Navigate to the Project

```bash
cd Tamanna-Portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
